# 机动车交通事故损害赔偿（中国大陆法）

## 适用场景

交通事故引发的人身伤亡、财产损失赔偿：协商、调解、诉讼；受害人索赔或保险公司/侵权人应诉。
产出：赔偿项目清单与金额测算 / 起诉状 / 答辩状 / 调解方案 / 内部案件评估。

**不适用**：纯粹的车损险理赔争议（无第三方侵权）；涉及交通肇事罪的刑事部分按刑事程序
（本技能只处理民事赔偿）；工伤与第三人侵权竞合的情形需另行处理。

## 第一步：定责任（赔偿比例的基础）

依据**《道路交通安全法》第76条（已核验）**与**《民法典》第1208条（已核验）**：

1. 先由**保险公司在交强险责任限额范围内**赔偿
2. 不足部分：
   - **机动车之间**：按各自**过错比例**分担
   - **机动车与非机动车驾驶人、行人之间**：非机动车/行人**无过错的，由机动车一方**承担；
     有证据证明其有过错的，**减轻**机动车一方责任；机动车一方无过错的，承担**不超过 10%** 的赔偿责任
   - 损失由非机动车驾驶人、行人**故意碰撞**机动车造成的，机动车一方**不承担责任**

> 操作要点：**责任认定书不等于赔偿比例**。认定书是行政认定，法院可不予采信或调整比例
> （尤其"同等责任"在民事赔偿中不必然 5:5，需结合过错程度与原因力）。起草时按认定书比例测算，
> 同时准备调整比例的论证（监控、鉴定、证人、行车记录仪）。

## 第二步：保险赔付顺序（先算保险，再算侵权人）

**《民法典》第1213条（已核验）**：先交强险 → 不足部分商业三者险按合同约定赔 → 仍不足或未投保商业险的，
由侵权人赔偿。

> 起草要点：
> - **交强险分项限额**（医疗费用 / 死亡伤残 / 财产损失三项限额）——**限额数值随政策调整，
>   引用前必须检索当期标准**，不得凭记忆写
> - 精神损害抚慰金、鉴定费、诉讼费等是否属于商业险赔付范围，**按保单条款与当地口径**判断，
>   常见争议点：商业险常将精神损害与鉴定费列为免赔或需附加险
> - 未投保交强险的，由投保义务人在交强险限额内**先行赔偿**（问清是否投保、是否脱保）
> - 商业险不足部分才轮到侵权人个人财产，起草诉请时**把保险列为被告/第三人**，
>   避免只起诉个人导致执行不能

## 第三步：损失项目逐项列（不要漏项、不要虚增）

**人身损害**（《民法典》第1179条已核验：医疗费、护理费、交通费、营养费、住院伙食补助费等
为治疗和康复支出的合理费用，以及因误工减少的收入；造成残疾的，还应当赔偿辅助器具费和残疾赔偿金；
造成死亡的，还应当赔偿丧葬费和死亡赔偿金）：

| 项目 | 计算口径 | 证据要求 |
|---|---|---|
| 医疗费 | 按实际发生（含后续治疗费，需鉴定或医嘱证明） | 病历、发票、费用清单；外购药需处方 |
| 住院伙食补助费 | 当地标准 × 住院天数 | 住院病历 |
| 营养费 | 医嘱或鉴定意见 × 天数 | 出院小结、鉴定意见 |
| 护理费 | 护理人员收入 × 护理期限（或当地护工标准） | 护理证明、收入证明、鉴定护理期 |
| 误工费 | 误工时间 × 收入减少（无固定收入按近三年平均或同行业标准） | 单位证明、工资流水、完税证明、鉴定误工期 |
| 交通费 | 实际必要支出（就医、转院、处理事故） | 票据，与就医时间地点吻合 |
| 残疾赔偿金 | 按伤残等级与**当地上一年度城镇居民人均可支配收入**计算年限 | 伤残鉴定意见书 |
| 被扶养人生活费 | 未成年人 / 无劳动能力且无其他生活来源的近亲属 | 户籍、亲属关系证明 |
| 辅助器具费 | 按普通适用器具的合理费用 | 配置机构意见、发票 |
| 死亡赔偿金 + 丧葬费 | 按当地上一年度标准计算 | 死亡证明、亲属关系证明 |
| 精神损害抚慰金 | 按伤残等级与当地口径 | 伤残鉴定、过错程度 |
| 财产损失 | 车辆维修/贬值、车上物品、停运损失（营运车辆） | 定损单、维修发票、营运证明 |

> ⚠️ **"当地上一年度"的统计数据（城镇居民人均可支配收入、职工平均工资等）必须检索当期公布值
> 并注明来源与年份**。这类数值每年更新、各省不同，凭记忆填写必然算错，也会让当事人对全部测算失去信任。

**与有过失**：受害人对损害发生或扩大有过错的，可**减轻**侵权人责任
（《民法典》第1173条，引用前须核验条号）。计算时按责任比例折减总额。

## 第四步：测算表（给客户一份算得清的表）

按下列结构输出：

```
一、责任与保险
   责任认定：XXX（附认定书编号）  拟定赔偿比例：X%
   交强险：医疗 X 元 / 死亡伤残 X 元 / 财产 X 元（限额依据：XXX，检索日期 YYYY-MM-DD）
   商业三者险：限额 X 元（免赔约定：XXX）
二、损失总额（逐项：项目 | 计算式 | 金额 | 依据条文 | 证据）
三、扣减与分担
   交强险内先赔：X 元
   超出交强险部分 × 赔偿比例 = X 元
   商业险承担：X 元（不足部分由侵权人承担 X 元）
   受害人自身过错折减：X 元
四、应付总额：X 元（其中保险 X 元、侵权人 X 元）
五、后续费用（取内固定物、二次手术、康复）：单列，注明需鉴定或医嘱
```

## 第五步：程序与期限要点
- **诉讼时效**：3 年（《民法典》第188条），自知道或应当知道权利受损及义务人之日起算；
  涉人身伤害的注意起算点争议（治疗终结 / 伤残鉴定作出）
- **伤残鉴定**：治疗终结后申请；鉴定机构资质与鉴定时机直接影响等级，提示律师把握时机
- **管辖**：侵权行为地或被告住所地法院
- **诉前保全**：涉营运车辆、外地当事人、保险不足的，评估是否申请财产保全
- **调解**：交警调解或自行调解达成的协议，注意写明**付款期限、逾期违约金、是否放弃后续索赔**
  （放弃后续治疗费索赔的条款需特别提示风险）
- **刑事责任交叉**：涉嫌交通肇事罪的，提示民事赔偿与刑事量刑的关系，但**不得承诺"赔钱免刑"**
