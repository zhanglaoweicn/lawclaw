# 期限值守晨报（Deadline Watch Briefing）

把「逾期 / 临期 / 开庭」扫描清单变成一份律师当天能照着做的晨报。交付物不是告警复述，是**动作 + 法条号**。

## 交付物规格（always-on）
- 一份中文晨报，**正文 ≤400 字**，固定三段：`一、今日必须处理` / `二、本周关注` / `三、风险提示`。
- 字数按 Word「字数」口径（汉字数 + 西文词数），**不是**含标点的字符数。交付前跑 `scripts/count_zi.py` 核对——凭感觉写必然超。
- 每条期限写成三段式：**期限类型（剩余/逾期天数）→ 今天要做的具体动作 → 法条号**。只写「已逾期」不算交付。
- 逾期项必须给残留救济路径，不能只报坏消息（对照表见下）。
- 条号核验结果、测试数据提醒等放在正文后的「附注」，显式标注「不计入正文」——律师要的是正文，核验过程是给同行看的。
- 结尾固定一句：「仅供参考，不构成正式法律意见」。
- 顺带建议给测试基准案件（案件名含「测试用」）加「测试」标签，避免与真实告警混排；测试案件的逾期项要明确写出「不构成真实失权」。

## 步骤
1. **先跑 `date '+%Y-%m-%d %A'`**。以系统日期为「今日」自己重算每条期限的剩余/逾期天数与星期——扫描结果里已经算好的天数是字符串，不要照抄。星期直接决定第 3 步。
2. **核验法条**（元典 MCP，可并行批量调）：`yuandian_rh_ft_detail(fgmc=法规全名, ftnum=中文条号)` 取正文 + `sxx`；条号记不准时用 `yuandian_rh_ft_search(keyword=法条原文片段)` 反查条号。**必须看到 `sxx: 现行有效` 才允许引用**。条号随修正漂移，凭记忆引用会引错；已验证的常用条号见 `references/期限法条速查.md`，但仍以当次查询为准。
3. **判日期性质**：期限末日落在周末或法定休假日的，按《民诉法》第85条第3款顺延至休假日后的第一日。若「今日」就是期限末日且今日正好是周末，给出当天可交付的路径——电子诉讼平台提交，或交邮（第85条第4款：期满前交邮不算过期）。顺延只在末日适用；末日是工作日就照常写「无顺延」。
4. **按段落笔**：
   - 今日必须处理 = 今日到期项 + 已逾期项
   - 本周关注 = 7 日内临期项 + 开庭准备要点（传票、证据原件、举证/证据清单、专利或权利要求比对表、证人出庭申请）
   - 风险提示 = 测试数据区分 + 停滞案件 + 失权风险
5. **数字数，超了就删**。压缩顺序：删修饰词 → 合并同案条目 → 砍背景铺垫。**法条号与动作句保留到最后。**

## 救济对照（逾期项写作用）
| 期限类型 | 法律后果 | 逾期后的残留救济 |
|---|---|---|
| 管辖异议 jurisdiction | 未在答辩期提出、且应诉答辩或反诉的，视为受诉法院有管辖权（《民诉法》第130条） | 仅违反级别管辖、专属管辖仍可争——核查案由与标的额 |
| 举证 evidence | 可不予采纳，或采纳但训诫、罚款（第68条） | 补交并书面说明理由；有正当理由可在障碍消除后 10 日内申请顺延（第86条） |
| 答辩 defense | 不答辩不影响法院审理（第128条） | 末日即今日则不适用顺延，当日提交或交邮 |
| 保全 preservation | 诉前保全后 30 日内不起诉/申请仲裁则解除（第104条）；续封逾期则当然解除 | 期限届满前申请续行查封、冻结（《民诉法解释》第485条），担保材料一并备妥 |
| 开庭 court-date | 缺席可径行判决 | 至少提前数日核对传票、证据原件与证人出庭申请 |
| 仲裁后起诉 arbitration-sue | **取决于裁决性质，后果相反** | 见下「必问律师」 |

## 必问律师 / 不许臆断
- 期限 key `arbitration-sue` 不携带裁决性质信息：劳动仲裁 = 收到裁决书之日起 15 日内起诉，期满裁决生效（《劳动争议调解仲裁法》第50条）；商事仲裁 = 申请撤销裁决（《仲裁法》2025修订第72条）。**在报告里把两支都写出来并请律师定性，不要二选一。**
- 期限 key 只是类型标签，不是事实。金额、时效起点、送达日期这类事实一律回案件文件核，不推断。

## 数据来源（别浪费时间找文件）
- 案件期限数据不在仓库里：案件存在前端 localStorage，后端由 `watchdog_sync` RPC 落盘到 `.hermes/data/watchdog_matters.json`，cron 扫描脚本读它。晨报直接吃用户给的扫描清单即可，**不要去 grep 仓库找案件文件或期限文件**。
- 值守架构、cron job 与 RPC 名称见仓库 AGENTS.md，本技能不重复。
