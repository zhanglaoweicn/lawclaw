# 财务专业智能体（FinSight / 财智）开发方案

> 基于 LawClaw（律爪）架构复刻，面向财务人员的垂直 AI 智能体

---

## 一、背景与目标

### 1.1 项目背景

LawClaw 已验证了"通用 AI Agent 框架 + 垂直领域深度定制"这一模式的可行性：
- **Tauri 桌面壳**提供跨平台交付和原生体验
- **Vue 3 + Element Plus** 提供响应式 UI
- **Hermes-agent** 提供成熟的 Agent 循环、工具调用、技能管理
- **MCP 协议**提供灵活的外部数据源集成
- **技能/专家角色体系**让领域知识可编排、可扩展

本项目旨在**复用 LawClaw 的核心架构**，将领域知识从法律迁移到财务/会计/税务，打造一款面向财务从业者的专业 AI 助手。

### 1.2 目标用户

| 用户画像 | 核心需求 |
|---------|---------|
| 企业财务人员（会计/出纳） | 账务处理、报表编制、报销审核、日常核算 |
| 税务专员/税务师 | 税务计算、纳税申报、税务筹划、政策解读 |
| 审计师（内审/外审） | 审计程序、底稿编制、风险评估、合规检查 |
| 财务分析师/FP&A | 财务分析、预算管理、预测建模、经营分析 |
| CFO/财务总监 | 决策支持、现金流管理、财务战略、风险管控 |
| 中小企业主（代账场景） | 简易记账、税务申报、财务健康诊断 |

### 1.3 核心价值主张

> **让每位财务专业人士拥有一个 24/7 的 AI 财务助理——懂准则、会算税、能分析、可审计。**

## 二、产品定位

### 2.1 命名建议

| 方案 | 中文名 | 寓意 |
|-----|-------|------|
| **FinSight** | 财智 | Financial + Insight，财务洞察 |
| FinClerk | 财算 | 财务计算助手 |
| FinMate | 财伴 | 财务伙伴 |
| AccuFlow | 金流 | 准确 + 现金流 |

**推荐：FinSight / 财智** —— 简洁、专业、与 LawClaw 命名风格一致。

### 2.2 品牌标识方向

- **配色**：深蓝（信任、专业）+ 翠绿（财务、增长）+ 金色（价值、精确）
- **图标**：指南针/罗盘元素（指引财务决策）或算盘+AI 的结合
- **字体**：无衬线字体为主，数据展示用等宽字体

### 2.3 与 LawClaw 的差异化

| 维度 | LawClaw（法律） | FinSight（财务） |
|------|----------------|------------------|
| 核心数据源 | 法律法规、裁判文书、案例库 | 会计准则、税法、财务数据 |
| 核心技能 | 合同审查、法律检索、文书起草 | 财务分析、税务计算、审计辅助 |
| 专家角色 | 律师（民事/刑事/IP等） | 会计师/税务师/审计师/CFO |
| 关键交互 | 案例管理、时间线、引用卡片 | 财务报表、数字仪表盘、图表 |
| 合规重点 | 法律条文引用准确性 | 会计准则遵循、税法合规 |

### 3.3 技术选型补充

| OCR | PaddleOCR | 发票识别、凭证录入 |
| 数值计算 | NumPy + pandas | 财务建模、数据分析 |

## 四、领域模型设计

### 4.1 核心实体

```typescript
// —— 核心领域类型（替代 legal.ts）——

// 账套 / 会计主体
interface AccountSet {
  id: string;
  name: string;              // 公司/主体名称
  taxId: string;             // 纳税人识别号
  accountingStandard: 'prc_gaap' | 'ifrs' | 'us_gaap'; // 会计准则
  fiscalYearStart: string;   // 会计年度起始月 (MM-DD)
  currency: string;          // 本位币 (默认 CNY)
  industry: string;          // 行业
  createdAt: string;
}

// 科目
interface Account {
  id: string;
  code: string;             // 科目编码 (如 1001)
  name: string;             // 科目名称 (如 库存现金)
  category: AccountCategory; // 资产/负债/权益/成本/损益
  level: number;            // 科目层级
  parentId?: string;        // 上级科目
  balanceDirection: 'debit' | 'credit'; // 余额方向
  isLeaf: boolean;          // 是否末级科目
}

// 凭证
interface Voucher {
  id: string;
  accountSetId: string;
  date: string;
  number: string;           // 凭证号
  summary: string;          // 摘要
  entries: VoucherEntry[];  // 分录（借贷平衡）
  attachments: string[];    // 附件
  status: 'draft' | 'posted' | 'audited';
  createdAt: string;
}

interface VoucherEntry {
  accountId: string;
  direction: 'debit' | 'credit';
  amount: number;
  summary?: string;         // 分录摘要
}

// 报表
type ReportType = 'balance_sheet' | 'income_statement' | 'cash_flow' | 'tax_return';

interface FinancialReport {
  id: string;
  accountSetId: string;
  type: ReportType;
  period: { start: string; end: string };
  items: ReportItem[];
  status: 'draft' | 'finalized';
  generatedAt: string;
}

// 税务记录
interface TaxRecord {
  id: string;
  accountSetId: string;
  taxType: 'vat' | 'citi' | 'personal_income' | 'stamp' | 'property' | 'other';
  period: string;           // 所属期 (YYYY-MM)
  payable: number;          // 应纳税额
  paid: number;             // 已纳税额
  dueDate: string;
  status: 'pending' | 'filed' | 'paid' | 'overdue';
}

// 业财任务/约定项目（替代 Matter）
interface Engagement {
  id: string;
  title: string;
  type: 'audit' | 'tax_filing' | 'bookkeeping' | 'financial_analysis' | 'consulting';
  clientName: string;
  status: EngagementStatus;
  deadline: string;
  team: string[];           // 成员
  materials: string[];      // 资料清单
  timeline: TimelineEvent[];
}

type EngagementStatus = 
  | 'proposed'    // 已立项
  | 'in_progress' // 进行中
  | 'review'      // 复核中
  | 'completed'   // 已完成
  | 'archived';   // 已归档
```

### 4.2 与 LawClaw 实体对照

| LawClaw (法律) | FinSight (财务) |
|---------------|-----------------|
| Matter (案件) | Engagement (项目/约定) |
| Case Stage (阶段) | Engagement Status (状态) |
| Citation (法条引用) | Regulation (法规引用) |
| Session + Matter (会话关联案件) | Session + Engagement (会话关联项目) |
| Timeline Event (时间线) | Timeline Event (时间线) |
| File (文件: 证据/文书) | File (文件: 凭证/报表/底稿) |
| 法律 Deadline | 税务 Deadline (申报期/缴款期) |

### 11.4 合规注意事项

- ⚠️ **审计辅助边界**：AI 不可替代注册会计师的专业判断
- ⚠️ **会计准则引用**：确保引用的准则版本是最新的

## 十三、风险评估

| 风险 | 可能性 | 影响 | 缓解措施 |
|------|-------|------|---------|
