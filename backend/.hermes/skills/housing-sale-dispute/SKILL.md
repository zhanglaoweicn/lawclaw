# 房屋买卖合同纠纷（中国大陆法）

## 适用场景

二手房买卖、商品房买卖引发的争议：卖方违约不卖/一房二卖、买方违约不买、逾期交房/逾期付款、
面积与质量不符、网签与限购导致的履行障碍、定金与违约金争议。
产出：律师函 / 起诉状 / 答辩状 / 解除通知 / 违约金与损失测算 / 内部案件评估。

**不适用**：纯租赁争议（用「房屋租赁」技能）；建设工程与开发商间的工程款争议；
征收拆迁补偿争议；小产权房等权属本身存疑的交易（需先解决权属）。

## 第一步：先定合同效力与履行阶段

| 检查项 | 影响 |
|---|---|
| 是否**网签/备案** | 影响"一房二卖"中的履行顺位与对抗效力 |
| 是否**已过户** | 已过户 → 买受人取得所有权，卖方违约基本只能赔；未过户 → 存在继续履行空间 |
| 是否**已交付** | 已交付但未过户的结合占有情况判断 |
| **买受人资格**（限购/限贷/社保年限） | 因买方自身资格无法过户 → 买方违约；因政策变化 → 可能构成情势变更或不可归责 |
| 房屋**权属瑕疵**（共有、抵押、查封、租赁在先） | 共有人未同意 → 效力待定/可能无效；有抵押/查封 → 履行障碍 |
| **定金**还是**订金** | 定金适用定金罚则；订金一般仅作预付款（文书用词不得混用） |

> ⚠️ 先分清"**不能履行**"（房屋已卖给第三人并过户、被查封）与"**不愿履行**"（卖方单纯涨价反悔）。
> 前者通常只能主张违约赔偿（含差价损失），后者买方可主张**继续履行**或解除索赔。

## 第二步：定性请求权基础

- **继续履行**：出卖人应当履行向买受人交付标的物或交付提取标的物的单证，并转移标的物所有权的义务
  （**《民法典》第598条 —— 已核验**）。未过户且不存在履行障碍时，买方可诉请判令协助过户
- **法定解除**（**第563条 —— 已核验**）：不可抗力致不能实现合同目的；履行期限届满前一方明确表示或以行为
  表明不履行主要债务；一方迟延履行主要债务经催告后在合理期限内仍未履行；迟延履行或其他违约行为致不能
  实现合同目的；法律规定的其他情形
- **质量/面积不符致不能实现合同目的**（**第610条 —— 已核验**）：买受人可以拒绝接受标的物或解除合同；
  拒绝接受或解除的，标的物毁损灭失的风险由出卖人承担
- **违约责任**（**第577条 —— 已核验**）：继续履行、采取补救措施或赔偿损失

## 第三步：金额测算（三个口径分开算，别混在一起）

```
一、已付款项
   已付房款 X 元 + 定金 X 元（区分定金/订金）→ 解除时可主张返还
二、违约金
   按合同约定（通常为总房价的 20% 或日万分之X）→ 与定金罚则只能择一（定金与违约金不并罚）
   ⚠️ 约定过高（一般超损失 30%）时对方可请求调减；过低时可请求增加
三、实际损失（差额损失为主）
   差价损失 = 起诉时（或解除时）同地段同类房屋市场价 − 合同价
   其他损失：中介费、贷款手续费、税费已支出、装修投入、搬迁费用、另购房屋多支出
   ⚠️ 违约金与损失赔偿的关系：一般按"择高主张"，避免重复计算被驳回
四、需现查的数值
   同地段同类房屋市场价 → 需评估报告或同小区网签成交数据佐证（注明来源与日期）
```

## 第四步：常见争点与应对

**一房二卖**：先看谁已过户（取得所有权者优先）；均未过户的看谁已合法占有、谁先网签、谁先付款；
恶意串通损害他人权益的合同无效。**先买受人**可向卖方索赔差价损失，不能要求已过户的次买受人腾房。

**定金与违约金**：守约方可择一主张，**不得并用**。定金罚则：给付定金方违约不得请求返还；
收受定金方违约应双倍返还。注意定金数额**不得超过主合同标的额的 20%**，超出部分不产生定金效力。

**限购/限贷导致无法履行**：区分①签约时买方隐瞒不具备资格（买方违约）；②政策在签约后出台且不可预见
（可主张情势变更或不可归责，双方互不承担违约责任，返还已付款）；③卖方明知买方无资格仍签约（混合过错）。
必须核查签约时点的当地政策与双方沟通记录。

**逾期交房/逾期办证**：按合同约定的日万分之X累计，注意**约定上限**（如"不超过总房价 5%"）；
无约定时按实际损失主张。诉讼时效 3 年，自违约行为发生或持续状态结束起算。

**面积差异**：按合同约定处理；未约定的，一般参照面积误差比绝对值 3% 作为分界
（超出部分买受人可请求解除或按约定处理）——**具体规则引用前须核验商品房买卖合同司法解释的条号与现行有效性**。

**税费与"阴阳合同"**：发现为避税签订两份不同价款合同的，提示税务与合同效力风险，
**不得协助制作阴阳合同**；若已存在，评估以哪份为准、能否补正。

## 第五步：程序要点
- **诉讼时效**：3 年（《民法典》第188条）；持续性违约注意起算点
- **管辖**：不动产纠纷由**不动产所在地**法院专属管辖
- **诉前保全**：涉一房二卖、卖方有转移财产迹象的，尽快申请查封该房屋或卖方财产
- **网签与预告登记**：未过户但已办**预告登记**的，可对抗后续处分（评估是否已办、能否补办）
- **证据**：合同、补充协议、网签记录、付款凭证、聊天与通话记录、中介带看与居间记录、
  同小区成交价数据、评估报告、限购政策文件（含发布日期）
