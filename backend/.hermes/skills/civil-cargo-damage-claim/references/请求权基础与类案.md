# 货损索赔 · 条文原文要点 · 类案 · 抗辩预判

供 `civil-cargo-damage-claim` 调用。条文均经元典智库核验为**现行有效**。

## 一、请求权基础条文（原文要点）

| 条文 | 原文要点 | 用途 |
|---|---|---|
| 《民法典》第904条 | 仓储合同是保管人储存存货人交付的仓储物，存货人支付仓储费的合同 | 确立仓储合同关系与**有偿性** |
| 《民法典》第917条 ★ | 储存期内，因保管不善造成仓储物毁损、灭失的，保管人应当承担赔偿责任。因仓储物本身的自然性质、包装不符合约定或者超过有效储存期造成仓储物变质、损坏的，保管人不承担赔偿责任 | **仓储货损核心请求权基础**；免责事由仅三类 |
| 《民法典》第918条 | 本章没有规定的，适用保管合同的有关规定 | 准用通道 |
| 《民法典》第892条 | 保管人应当妥善保管保管物；当事人可以约定保管场所或者方法，除紧急情况或为维护寄存人利益外不得擅自改变 | 经第918条准用，义务内容 |
| 《民法典》第897条 | 保管期内，因保管人保管不善造成保管物毁损、灭失的，保管人应当承担赔偿责任。但是，无偿保管人证明自己没有故意或者重大过失的，不承担赔偿责任 | 保管合同请求权基础（注意但书） |
| 《民法典》第893条 | 寄存人对保管物瑕疵或特殊保管措施的告知义务 | ⚠️ **不是**保管人赔偿依据 |
| 《民法典》第714条 | 承租人应当妥善保管租赁物，因保管不善造成毁损、灭失的，应当承担赔偿责任 | 定性为租赁时的替代基础 |
| 《民法典》第509条 | 全面履行；依诚信原则履行通知、协助义务 | 保管人未及时通知/未防范的独立违约 |
| 《民法典》第577条 | 违约责任方式 | 责任方式 |
| 《民法典》第584条 | 损失赔偿额相当于违约造成的损失，含履行后可获利益；受可预见性规则限制 | 赔偿范围 |
| 《民法典》第591条 | 减损规则；防损合理费用由违约方负担 | 双刃：支撑施救费，也是对方最强抗辩 |
| 《民法典》第590条 | 不可抗力免责；须及时通知并在合理期限内提供证明 | 对方抗辩条款 |
| 《民法典》第496、497条 | 格式条款提示说明义务；不合理免除减轻提供方责任的条款无效 | 击破合同赔偿限额/免责条款 |
| 《民法典》第188条 / 第195条 | 三年时效 / 权利人提出履行请求致时效中断 | 时效与催告功能 |
| 《民事诉讼法》第24条 | 合同纠纷由被告住所地或合同履行地法院管辖 | 管辖（仓储物所在地可主张为履行地） |
| 《民事诉讼法》第103条 | 财产保全 | 后果表述 |
| 《民诉法解释》第107条 | 诉讼中为达成调解/和解协议作出妥协而认可的事实，不得在后续诉讼中作为对其不利的根据 | ⚠️ 仅覆盖诉讼中 |

## 二、类案责任比例（关键：全额支持罕见）

| 案号 | 事实 | 裁判要旨 |
|---|---|---|
| （2026）豫1122民初2305号 | 冷库漏水致储存辣椒受损，双方签署损失明细确认金额 | 仓储人负妥善保管法定义务；**无论漏水系设备老化、第三方过错或自身管理疏失，均不影响保管人依约承担违约责任**；双方共同签署的损失确认文件具有证据效力 |
| （2021）粤01民终31051号 | 台风水浸硅钢片（保险人代位求偿） | 台风已有预警不构成不可抗力；保管人未防范、14天后才发现，判承担80%责任 |
| （2022）豫11民终232号 | 暴雨及仓库设施缺陷致副食品受损 | 保管人70%、存货人30%；运费、挪库费等直接损失计入赔偿范围 |
| （2021）津01民终1398号 | 暴雨积水倒灌致货物受损 | 保管人未尽妥善保管义务应赔偿；损失扣除残值（该案扣30%残值）并按酌定比例 |
| （2025）内05民终2500号 | 库房漏水致化肥农药受损（租赁关系） | **反面案例**：存货人未举证损失与漏水的因果关系、未采取防潮措施，承担举证不能后果而败诉 |

## 三、对方抗辩预判与回应

| 抗辩 | 依据 | 回应 |
|---|---|---|
| 不可抗力（暴雨/台风） | 第590条 | 不可抗力须“不能预见、不能避免、不能克服”且须及时通知并在合理期限内提供证明；**已预警的强降雨/台风不构成不可抗力** |
| 落入第917条法定免责事由 | 第917条后段 | 漏水不属于自然性质、包装不符合约定、超过有效储存期三者之一 |
| 损失系第三方（物业/楼上/市政排水）造成 | 合同相对性 | **漏水原因不属于违约责任认定的必要查明事项**，保管人不得以成因抗辩 |
| 存货人自身过错、未采取减损措施 | 第591条 | 实务中最有效的抗辩，直接压缩赔偿比例。须备齐己方已及时通知、已施救隔离、已减损的证据 |
| 损失金额过高、公估系单方委托 | 举证责任 | 以双方共同签署的货损清点文件优先；预估对方申请重新鉴定 |
| 合同赔偿限额/免责条款 | 合同约定 | 依第496、497条评估其效力 |

## 四、起草前必须清零的核实清单

- [ ] 合同原件：名称、性质、条款全文（保管义务、赔偿责任、**赔偿限额**、通知、争议解决）
- [ ] 合同有无仲裁条款；有无约定索赔期限、付款期限
- [ ] 货损事件日期、持续时长、部位、原因认定材料与维修记录
- [ ] 己方发现并通知相对方的日期、方式及送达凭证
- [ ] 双方共同签署的货损清点文件（有无、签署人、金额）
- [ ] 公估报告（编号、日期、机构、结论、残值）与索赔金额完整构成明细
- [ ] 是否投保财产险、是否已理赔、理赔金额
- [ ] 案件是否已立案（决定本函为诉前函还是诉讼中函）
- [ ] 己方是否欠付仓储费（反诉风险）
