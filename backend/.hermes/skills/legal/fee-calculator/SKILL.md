# 诉讼费计算 Skill

当用户需要计算诉讼费用、保全费用、执行费用时使用本 skill。

## 计算依据
- 《诉讼费用交纳办法》（国务院令第481号）
- 各地高院收费标准（如有差异，以当地为准）

## 案件受理费（财产案件，按标的额分段累计）
| 标的额区间 | 费率 | 速算增加额 |
|---|---|---|
| 不超过1万元 | 50元/件 | — |
| 1万元-10万元 | 2.5% | — |
| 10万元-20万元 | 2% | +300元 |
| 20万元-50万元 | 1.5% | +1300元 |
| 50万元-100万元 | 1% | +3800元 |
| 100万元-200万元 | 0.9% | +4800元 |
| 200万元-500万元 | 0.8% | +6800元 |
| 500万元-1000万元 | 0.7% | +11800元 |
| 1000万元-2000万元 | 0.6% | +21800元 |
| 超过2000万元 | 0.5% | +41800元 |

## 非财产案件
- 离婚案件：50-300元/件
- 人格权侵权：100-500元/件
- 知识产权民事案件：500-1000元/件
- 劳动争议：10元/件

## 保全费
| 保全金额 | 费率 |
|---|---|
| 不超过1000元 | 30元/件 |
| 1000元-10万元 | 1% |
| 超过10万元 | 0.5%，最高5000元 |

## 申请执行费（《诉讼费用交纳办法》第14条第(一)项，按执行标的额分段累计）
| 执行标的额区间 | 费率 | 速算增加额 |
|---|---|---|
| 没有执行金额或价额 | 50-500元/件 | — |
| 不超过1万元 | 50元/件 | — |
| 1万元-50万元 | 1.5% | — |
| 50万元-500万元 | 1% | +2400元 |
| 500万元-1000万元 | 0.5% | +27400元 |
| 超过1000万元 | 0.1% | +67400元 |

计算方式与受理费同为「标的额 × 档位费率 + 速算增加额」。**注意**：执行费的分档与受理费
完全不同（受理费第一档是 1 万以下 50 元 + 1-10 万 2.5%），不要互相套用；
也要与「保全费」区分（保全费另有 5000 元封顶）。

**本技能未覆盖、需另行核验的项目**：上诉案件与申请再审的受理费、支付令、公示催告、
管辖权异议不成立、行政案件的收费标准。律师问到这些时，请说明本表未覆盖，并建议通过
「法条速查」核对《诉讼费用交纳办法》相应条款后再给结论——不要凭记忆套用例外的比例。

## 注意事项
- 计算结果为预交金额，实际以法院通知为准
- 胜诉方可要求败诉方承担诉讼费
- 简易程序审理减半收取
- 调解结案减半收取
- 如用户不提供标的额，询问后再计算
