# 房屋租赁合同纠纷（中国大陆法）

## 适用场景

房屋租赁争议：欠租与解除、押金不退、提前退租与违约金、转租争议、装修物与添附、
房屋被出售后新业主收房（买卖不破租赁）、承租人优先购买权被侵害。
产出：律师函 / 解除通知 / 起诉状 / 答辩状 / 金额测算 / 内部案件评估。

**不适用**：商业物业的招商合作/联营（法律关系不同）；公有住房与保障房的特殊规则；
以租代售（实为买卖）；厂房与土地租赁涉及土地管理的特殊情形。

## 第一步：核对基础事实（决定适用哪套规则）

| 检查项 | 要点 |
|---|---|
| **租赁期限** | 超过 6 个月**应当采用书面形式**；未采书面形式的视为**不定期租赁**（双方可随时解除，但需合理期限通知） |
| 是否**登记备案** | 未备案**不影响合同效力**，但影响对抗与举证便利 |
| **实际交付与占有** | 占有事实是"买卖不破租赁"与转租认定的基础 |
| **转租** | 是否经出租人同意（第716条，见下） |
| **押金性质** | 是"押金/保证金"还是"定金"——决定能否直接抵扣与是否适用定金罚则 |
| **装修** | 是否经同意、是否形成附合、有无装修清单与发票（决定退租时能否主张补偿） |
| **是否已被出售** | 涉"买卖不破租赁"或优先购买权争议 |

## 第二步：核心规则与定性

**租赁合同定义**（**《民法典》第703条 —— 已核验**）：出租人将租赁物交付承租人使用、收益，
承租人支付租金。

**租金支付期限**（**第721条 —— 已核验**）：按约定期限支付；未约定或约定不明且不能确定的，
租赁期限不满一年的应在**届满时**支付；一年以上的应在**每届满一年时**支付，剩余期限不满一年的在
**剩余期限届满时**支付。

**迟延付租与解除**（**第722条 —— 已核验**）：承租人**无正当理由**未付或迟延付租的，
出租人可以请求其在**合理期限内**支付；**逾期不支付的，出租人可以解除合同**。
> ⚠️ 程序要点：出租人解除前**必须先催告并给合理期限**。直接换锁、断水电、清空房屋 = 违法
> **私力救济**，可能构成侵权并承担赔偿责任。起草解除通知时必须写清催告期限。

**转租**（**第716条 —— 已核验**）：经出租人同意可以转租，转租后原租赁合同继续有效，
第三人造成损失的由**承租人赔偿**；**未经出租人同意转租的，出租人可以解除合同**。
> 注意"视为同意"规则：出租人知道或应当知道转租但**6 个月内未提出异议**的，视为同意转租
> （该规则引用前须核验条号与现行有效性）。因此时间点很关键——尽快查清出租人何时知情。

**买卖不破租赁**（**第725条 —— 已核验**）：租赁物在**承租人按租赁合同占有期限内**发生所有权变动的，
**不影响租赁合同的效力**。新买受人须继续履行至租期届满。
> 仍可能无法对抗的情形：房屋在**出租前已设抵押**并被抵押权人依法处置、或**已被查封**的
> （需按当地口径判断，提示律师核查他项权利设立时间）。

**承租人优先购买权**（**第726条 —— 已核验**）：出租人出卖租赁房屋的，应在出卖前**合理期限内通知**承租人，
承租人享有以**同等条件**优先购买的权利；但**房屋按份共有人行使优先购买权**或
**出租人将房屋出卖给近亲属**的除外。出租人履行通知义务后，承租人**15 日内未明确表示购买的，
视为放弃**。

**侵害优先购买权的后果**（**第728条 —— 已核验**）：出租人未通知或有其他妨害承租人行使优先购买权情形的，
**承租人可以请求出租人承担赔偿责任**；**但出租人与第三人订立的房屋买卖合同的效力不受影响**。
> ⚠️ 因此不能请求确认买卖合同无效，只能索赔损失（含差价损失）——起草诉请时不要写"请求确认无效"。

## 第三步：金额测算（退租与欠租两个场景）

```
场景 A：出租人主张（欠租 / 提前退租）
  欠付租金 X 元（按合同标准 × 欠付期间）
  逾期违约金 X 元（按约定日万分之X；过高可被调减）
  押金抵扣：优先冲抵欠租与违约金，剩余退还
  房屋损坏修复费用 X 元（需有验收记录/照片/报价单佐证，不得凭空主张）
  空置损失（提前退租）：一般按约定违约金，或按合理空置期（1-3 个月）的租金主张
场景 B：承租人主张（出租人违约 / 押金不退 / 提前收回房屋）
  已付押金退还 X 元（扣除证据充分的实际损失后）
  装修损失：经同意的装修 → 按剩余租期折算残值或协商补偿；
            未经同意的装修 → 一般不予补偿（可能还需恢复原状）
  搬迁与另租差价损失
  营业损失（商业租赁）：需有实际经营证据与因果关系
场景 C：优先购买权被侵害
  差价损失 = 实际出售价与"同等条件"下本可购买价的差额（需证明"同等条件"可满足：资金能力证明）
  ⚠️ 需证明"即使通知也会购买"且具备同等条件，否则索赔可能不成立
```

## 第四步：常见争点与应对
- **不定期租赁的解除**：双方可随时解除，但出租人需**合理期限前通知**；"合理期限"由法院酌定，
  一般 1 个月以上，商业物业更长
- **押金与违约金并用**：押金是担保，违约金是责任，押金可抵扣违约金但**总额不得超出实际损失过多**
- **群租与改变用途**：承租人擅自改变结构/群租的，出租人可依合同与相邻关系主张解除与恢复原状
- **物业费、水电费、暖气费**：按合同约定与实际承担主体划分；约定由承租人负担的不得对抗物业公司
  （物业公司可向产权人主张后内部追偿）
- **疫情/政策导致的经营困难**：曾出台过租金减免的司法政策指引，**现行是否适用须核验当期指导意见**，
  不得直接套用旧政策
- **二房东跑路**：承租人已付租金但"二房东"未向产权人付租 → 核查转租是否经同意、
  有无产权人收取租金的记录（可能构成事实同意），据此决定能否对抗产权人收房

## 第五步：程序要点
- **诉讼时效**：3 年（《民法典》第188条）；租金债权按各期分别起算
- **管辖**：不动产纠纷由**不动产所在地**法院专属管辖
- **证据**：租赁合同与补充协议、付款凭证、交房与验收记录（含照片）、催告与解除通知的送达凭证、
  微信/短信沟通记录、维修与装修凭证、产权与抵押查询信息
- **送达**：解除通知务必用可留痕方式送达（EMS 注明文件内容、微信+短信双发、必要时公证送达）
- **私力救济禁令**：不得建议换锁、断水断电、强行清房；已发生的，评估对方反诉与赔偿风险
