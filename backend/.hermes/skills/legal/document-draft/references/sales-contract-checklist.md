# 产品销售合同起草检查清单

## 签约主体
- [ ] 双方全称与营业执照一致
- [ ] 法定代表人或授权代表明确
- [ ] 联系方式和送达地址完整

## 标的与价格
- [ ] 产品名称、规格型号清晰无歧义
- [ ] 数量单位明确（件/台/吨等）
- [ ] 单价与总价核对一致
- [ ] 含税/不含税明确，税率注明
- [ ] 价格是否含运费、安装费、培训费

## 质量与验收
- [ ] 质量标准来源明确（国标/行标/企标/约定）
- [ ] 验收期限约定（建议5-10个工作日）
- [ ] 质量异议期约定
- [ ] 隐蔽瑕疵检验期约定（建议3-12个月）
- [ ] 技术资料交付清单

## 交付
- [ ] 交货时间明确（具体日期或条件）
- [ ] 交货地点明确
- [ ] 运输方式和费用承担方明确
- [ ] 风险转移节点明确（交付前后）

## 付款
- [ ] 付款节奏合理（预付款+交货款+质保金）
- [ ] 各期付款比例和金额明确
- [ ] 付款前提条件清晰（验收合格/开票）
- [ ] 收款账户信息完整

## 违约与救济
- [ ] 逾期交货违约金比例（建议日万分之三至五）
- [ ] 逾期付款违约金比例
- [ ] 根本违约解除权
- [ ] 不可抗力条款
- [ ] 损失赔偿范围

## 其他
- [ ] 知识产权保证条款
- [ ] 保密条款及期限
- [ ] 争议解决方式（仲裁或诉讼，不可并存）
- [ ] 合同生效条件
- [ ] 附件清单列明
- [ ] 合同份数和持有方
